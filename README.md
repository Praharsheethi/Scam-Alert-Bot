# 🛡️ Scam Alert Bot

## 🚀 Overview
The **Scam Alert Bot** is a machine learning-powered application designed to detect potential scam messages. It utilizes **natural language processing (NLP)** techniques to analyze text and classify whether a given message is likely to be a scam.

---

## 📌 Features
✅ **Machine Learning Model** – Detects scam messages with trained algorithms  
✅ **Dataset Processing** – Scripts for dataset generation & preprocessing  
✅ **Gradio Interface** – Web-based UI for scam detection  
✅ **Real-time Prediction** – Instant results for scam classification  
✅ **Data Collection & Analysis** – Helps improve detection accuracy  

---

## 🛠️ Installation
### 🔹 Install Dependencies

pip install -r requirements.txt



### 🔹 Prerequisites
Ensure you have the following installed:
- 🐍 **Python 3.x**
- 📦 **Pip (Python package manager)**



### 🔹 Clone the Repository

git clone https://github.com/Praharsheethi/Scam-Alert-Bot.git
cd Scam-Alert-Bot

--- 

##  🎯 Usage
#### ▶️ Running the Scam Alert Bot

python app.py
This will start the application for scam detection.

#### ▶️ Launching the Gradio Interface

python gradio_interface.py
This will open a web-based UI where you can input text for scam detection.

#### ▶️ Training the Model


python train_test.py
This script will preprocess data, train the model, and save it for later use.
